# Сбер Финансы — аудит выписки и подписок

Прототип анализирует банковские выписки CSV/XLS/XLSX/PDF, проверяет распознанные строки и ищет подтверждённые регулярные платежи. Полная история транзакций больше не показывается в интерфейсе и не попадает в JSON-экспорт; она используется только внутри текущего анализа для итогов, графиков и поиска подписок.

## Что усилено

- Каждая строка проходит локальную проверку даты, суммы, названия/merchant и описания.
- Одинаковые дата + сумма + описание больше не удаляются автоматически: реальные повторные операции сохраняются, а возможные дубли только учитываются в аудите.
- Денежные итоги складываются в копейках, без округления каждой суммы до целого рубля.
- Даты валидируются строго: не принимаются несуществующие календарные даты.
- При подключённом DeepSeek каждая строка небольшими пакетами отправляется на сервер приложения вместе с исходной строкой `raw_source`. AI сверяет распознанные `date`, `amount`, `merchant_name`, `description` и при наличии явного сигнала — направление операции.
- AI-исправления даты/суммы/направления применяются только при очень высокой уверенности и только после серверной проверки, что предложенное значение действительно присутствует в исходной строке.
- Подписки проходят второй отдельный AI-проход: проверяются все даты evidence, суммы, название, описания, cadence и наблюдаемая сумма.
- Для AI включён DeepSeek V4 Pro в thinking-режиме с `reasoning_effort=max`.
- «Подписки / мес» теперь учитывает периодичность: недельные платежи переводятся в месячный эквивалент, квартальные делятся на 3, годовые — на 12 и т.д.
- Раздел с полной историей операций удалён.
- Поиск в верхней панели переделан в компактное поле с лупой внутри; он ищет разделы, действия и найденные подписки.

## Защита от выдуманных операций

1. Источник истины для первой AI-проверки — реальная `raw_source` строка из файла.
2. AI обязан вернуть покрытие по каждому `transaction_id`; сервер считает фактический процент проверенных строк.
3. Любая предлагаемая коррекция даты/суммы перепроверяется сервером по исходной строке.
4. AI не может создать новую транзакцию.
5. В кандидаты на подписку попадают только повторяющиеся исходящие операции без локального veto.
6. Сервер принимает ответы подписочного AI только для существующих `candidate_id`.

## Запуск

```bash
npm install
cp .env.example .env
# вставьте DEEPSEEK_API_KEY в .env
npm start
```

Откройте `http://localhost:3000`.

Без API-ключа сайт продолжает работать в локальном режиме: парсинг, аудит сумм, категории, аналитика и консервативный поиск подписок остаются доступны.

## Переменные окружения

```env
DEEPSEEK_API_KEY=...
DEEPSEEK_MODEL=deepseek-v4-pro
DEEPSEEK_REASONING_EFFORT=max
PORT=3000
```

## Поддерживаемые файлы

- CSV
- XLS
- XLSX
- PDF с текстовым слоем

PDF-выписки банков сильно отличаются по разметке. Для сканов и фотографий по-прежнему нужен OCR или отдельная серверная обработка изображений.
